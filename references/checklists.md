# 专项检查清单（按需加载）

> 识别到对应功能类型或关键词时套用。

## 一、8 类功能检查清单

| 类型 | 测试重点 |
|------|----------|
| **表单类**（登录/注册/搜索/提交/编辑） | 输入验证：必填空值/空格/null、长度最小最大超长、格式（邮箱/手机/身份证/URL）、特殊字符 `<script>`/SQL/emoji、边界 0/-1/最大/最小；业务规则：唯一性、外键存在性与状态、权限、并发重复提交；体验：提交反馈、字段级错误、失败数据保留、撤销 |
| **列表类**（用户/订单/报表） | 展示：空态/加载态/分页（页码/每页/总数）/多字段排序稳定性/多条件筛选与重置；数据量：1 条/大量/海量虚拟滚动/长期增长；操作：全选反选批量、单条增删改查、危险操作二次确认、操作后刷新 |
| **购物车类** | 商品管理：加购（正常/缺货/下架）、改数量边界、删除单品/批量/清空、加购后价格库存变化；价格：单价×数量与小数精度、满减/折扣/券叠加、总价运费税费；并发一致性：并发加购/改量/最后一件竞争/多端同步；结算：库存价格券校验、支付成功失败超时、订单创建与扣减、中断/重复支付/退款 |
| **支付类** | 金额安全：精度与四舍五入、边界 0/负数/超大/小数、重复支付、并发扣款、部分退款余额；状态一致性：待支付/支付中/成功/失败、超时、回调丢失/重复、对账；异常：网络中断、余额不足/限额、重复回调、退款失败/部分/多次 |
| **导入导出类** | 文件：Excel/CSV/TXT、UTF-8/GBK/ANSI、空文件空行空列、大文件超时、损坏文件；数据：列映射/顺序/缺失、格式与业务校验、部分成功、去重覆盖、换行制表符编码；反馈：进度、成功失败条数、逐行错误详情、错误文件下载 |
| **审批类** | 流程：正常/跳过/回退节点、谁审批/查看/操作、同意/拒绝/转办/退回、超时催办自动审批；状态：待审批/审批中/通过/拒绝、拒绝后重提、并发审批、审批中撤回；通知：新申请/结果通知、超时催办、渠道（站内/邮件/短信/推送） |
| **通知类** | 发送：触发事件、实时/定时/批量、渠道、频率限制与去重；接收：订阅/屏蔽、未读标记/列表/详情、已读删除、历史持久化与搜索；异常：发送失败重试记录、渠道拒收、用户不存在 |
| **权限类** | 访问控制：角色功能权限、数据权限、越权拦截、权限继承；角色管理：角色增删改、用户绑定解绑、多角色权限叠加、权限审计；异常：越权拦截、权限降级后旧请求、并发权限变更 |

## 二、接口测试（关键词：接口/API）

- 6 维覆盖：功能 40% / 安全 20% / 异常 15% / 性能 10% / 契约 10% / 兼容 5%。最低覆盖：功能 + 参数组合 + 安全/鉴权。
- 功能：正向、反向、边界、参数组合、业务规则；校验入参（类型/长度/格式/必填）、返回（状态码/响应体/响应头）、业务（数据正确/状态变更）、异常（错误码/错误信息）。
- 安全：认证（Token/Session/OAuth）、授权（水平/垂直越权）、注入（SQL/XSS/命令）、数据（加密/脱敏/敏感泄露）、速率限制。
- 异常：连接/读取超时、重试（幂等/退避/上限）、降级/熔断/限流、空响应/部分数据/数据损坏。
- 契约与兼容：消费者驱动契约、版本向后/向前兼容、协议一致性（REST/GraphQL/gRPC/WebSocket）、上游/中间件/SDK 集成。
- Mock 时机：第三方、不稳定依赖、未就绪接口、异常/超时/限流、特定数据。
- 接口类型重点：REST 状态码与 HTTP 语义；GraphQL 查询复杂度/N+1/细粒度权限；gRPC 消息格式/流/超时重试；WebSocket 连接管理/心跳/消息顺序。

## 三、移动端测试（关键词：移动端/App/小程序/H5/桌面）

- 6 维覆盖：功能 35% / 兼容 25% / 中断 15% / 性能 10% / 弱网 10% / 安全 5%。最低覆盖：中断/网络/权限/兼容。
- 功能与中断：安装/卸载/覆盖升级/跨版本、卸载重装、核心流程、数据持久化、离线；来电短信、通知、低电量、网络切换、前后台切换、闹钟。
- 兼容矩阵：小/标准/大/折叠屏，720p-4K，iOS 14+/Android 8+，手机/平板/折叠，主流品牌；系统权限/通知/后台/存储策略。
- 弱网：WiFi/4G/5G 及切换、高延迟 >500ms、低带宽 <100kbps、丢包 >10%、抖动。
- 性能基线：冷启 <2s、温启 <1.5s、热启 <1s；内存 <200MB（峰值 <300MB 无泄漏）；待机耗电 <5%/天、使用 <15%/h；首载流量 <5MB；帧率 >55fps。
- 平台专项：App—安装升级/中断/兼容/性能/UX（布局适配、手势、返回逻辑、无障碍）。小程序—生命周期（冷/热/温启动、onLoad/onShow/onHide）、授权、微信支付回调、分享带参、跳转类型、基础库版本兼容、分包体积（主包/分包 <2MB、总 <20MB）。H5—响应式断点（320/480/768/1024/1200）、触摸手势与 300ms 延迟、内置浏览器兼容、首屏 <2s、SEO。桌面—窗口管理/多窗口、快捷键、文件打开保存导入导出、系统集成（剪贴板/通知/托盘/主题）、多显示器。PC Web—浏览器兼容、布局断点与缩放、表单与防重复提交、会话（多标签/超时/强制下线）、路由与前进后退、拖拽。

## 四、Agent 测试（关键词：Agent/智能体/对话助手）

- 9 维覆盖：功能 25% / 安全 15% / 高级安全 12% / 边界 10% / 可控性 12% / 可靠性 8% / 幻觉与事实性 8% / 推理链 5% / 工具调用 5%。最低覆盖：工具调用 + 幻觉 + 安全审计中至少 2 项。
- 功能：任务执行（单任务/队列/分解/优先级）、决策（意图/方案选择/风险/资源）、交互（多轮/上下文记忆/知识/工具使用）、工具调用（选择/参数生成/工具链编排/失败处理/滥用检测/副作用控制）。
- 安全：输入注入/越权/敏感/恶意；输出隐私/内容安全/准确性/可控；行为权限边界/资源限制/异常/审计日志。高级：间接注入（RAG 文档/网页/工具返回）、多轮诱导（渐进/角色扮演/上下文伪造）、编码绕过、权限提升。
- 边界：空/超长/特殊格式/多模态输入；能力外/矛盾/循环依赖/资源耗尽；多用户/多任务/多工具/状态并发。
- 可控性：关键决策人工确认/高风险复核/确认超时；强制中止/任务取消/超时；沙箱/资源限制/限流/操作日志；自我认知边界/拒绝/非静默降级。
- 幻觉与事实性：真实性/时效性/数值核查、不确定表述、猜测标注、来源归因与引用保真、RAG 相关性/召回不足/多文档冲突。
- 推理链：可解释性/步骤可追溯/决策归因；逻辑跳步/循环/矛盾/相关因果混淆；自我纠错；冗余步骤/过早承诺/时延。
- 可靠性：24h+ 长稳、大请求、异常恢复、降级；工具/知识库/网络/依赖故障容错；状态/输出/决策/日志一致性。
- 类型必测：对话助手=功能+安全+幻觉；任务执行=功能+工具调用+可控性；数据分析=功能+幻觉+推理；自主决策=安全+可控性+推理+工具调用。

## 五、性能 / 安全 / 兼容（关键词：性能/压力/安全/渗透/兼容）

- 性能：负载（阶梯并发）、压力（至崩溃，找极限与恢复）、稳定性 Soak（24-72h，泄漏/资源/衰减）、尖峰（突发并发）。指标 P50/P95/P99（目标 P99<1s）、TPS/QPS、错误率 <0.1%、CPU/内存/磁盘IO/网络IO 各 <80%。
- 安全：OWASP Top 10（注入、失效认证、敏感数据暴露、XXE、越权、配置错误、XSS、不安全反序列化、组件漏洞、日志不足）、渗透测试、代码审计。**安全测试须先获得书面授权、限定范围与环境**。
- 兼容：浏览器（Chrome/Firefox/Safari/Edge 及版本）、设备（PC/手机/平板/分辨率）、系统（Windows/macOS/Linux/iOS/Android）、网络（WiFi/4G/5G/弱网/离线）。
- 前置：仅在功能测试通过后开展；每维明确"测什么/怎么测/何时算够"。

## 六、用例级别与风险等级参考

| 级别 | 定义 | 占比 |
|------|------|------|
| P0 | 核心业务流程、崩溃/主流程阻断 | ≤20% |
| P1 | 主要功能、重要分支、体验受损 | ≤40% |
| P2 | 次要功能、异常场景 | ≤30% |
| P3 | 边缘场景、极端异常、优化类 | ≤10% |

> 缺陷/风险严重度可反向对应：崩溃/核心不可用=高(P0)，数据错误=高，界面/文案=低(P3)。
